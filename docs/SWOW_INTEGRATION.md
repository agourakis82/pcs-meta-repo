# SWOW Integration in PCS v4.3

## Overview
This module integrates SWOW datasets for EN/ES/NL/ZH into the PCS project.

## License Reminder
SWOW data is CC BY-NC-ND 3.0. **No redistribution of raw data**. Code only.

## Quick Start
1. Download SWOW data manually from official site.
2. Place in `data/raw_public/swow/<lang>/`
3. Run `make swow-<lang>`
