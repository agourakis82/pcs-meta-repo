# PCS v4.4 - Modality Separation Technical Specification

**Version**: v4.4  
**Date**: December 19, 2024  
**Status**: Implementation Ready  
**Objective**: Surgical and auditable approach to incorporate 4 datasets (DERCo, GECO, LPP, OneStop) with modality split (EEG/RT) without breaking existing functionality.

---

## 0. Executive Summary

### Objective (v4.4)

**Separate** ingest and outputs by **modality**:
- **RT/ET** (Reading Time): ZuCo-RT, GECO, OneStop
- **EEG**: ZuCo-EEG, DERCo, LPP

**Key Features**:
- Standardize schema (`word_events_rt.parquet` / `word_events_eeg.parquet`)
- **Join KEC** by `(lang, word)` 
- Maintain **merged** file for compatibility
- Emit **artifacts per dataset** (integration/models/figures)
- **QA/Provenance** per dataset

## 2. Loaders by Modality (L0→L1 "tidy")

> Produce **one file per modality** with harmonized schema.

### 2.1 RT/ET → `word_events_rt.parquet`

**Loaders**:
- `src/datasets/zuco_rt_loader.py`
- `src/datasets/geco_loader.py`
- `src/datasets/onestop_loader.py`

**Minimum Schema (columns)**:
```
lang, subject_id, task_id, doc_id, sent_id, word_id, word,
ffd_ms, gd_ms, trt_ms, nfix,
length, logfreq, position
```

**Rules**:
- Normalize `word` (lowercase, strip/diacritics) — same filter applied to KEC
- Filter placeholders: `^word_?\d+$` and invalid ET (all ET=0 → drop)
- Units in **ms**; missing metadata → **NaN** (never synthesize)
- Validate with `validate_word_events_rt()`

### 2.2 EEG → `word_events_eeg.parquet`

**Loaders**:
- `src/datasets/zuco_eeg_loader.py`
- `src/datasets/derco_eeg_loader.py`
- `src/datasets/lpp_eeg_loader.py`

**Minimum Schema (columns)**:
```
lang, subject_id, task_id, doc_id, sent_id, word_id, word,
eeg_metric, theta, alpha, beta, onset_ms, offset_ms,
length, logfreq, position
```

**Rules**:
- `eeg_metric` = primary measure (ERP window/band power); `theta/alpha/beta` optional
- Align by **word** whenever possible; otherwise, see **LPP** below
- Validate with `validate_word_events_eeg()`

## 3. Integration and Joins with KEC (L2)

### 3.1 KEC (existing, L2)

- `data/L2_derived/kec/<lang>/`: `entropy.parquet`, `curvature.parquet`, `coherence.parquet`, `components.parquet`, `edges.parquet`, `kec_nodes.parquet`
- **Lexical key**: `(lang, word)` — apply **same normalization** used in loaders

### 3.2 Integrated Tables (per dataset/modality)

**Directory**: `data/processed/v4.4/integration/`

**Files**:
- `zuco_kec_rt.parquet`   = `zuco_rt.word_events_rt` ⟂ `kec_nodes` (via `(lang, word)`)
- `zuco_kec_eeg.parquet`  = `zuco_eeg.word_events_eeg` ⟂ `kec_nodes`
- `geco_kec_rt.parquet`
- `onestop_kec_rt.parquet`
- `derco_kec_eeg.parquet`
- `lpp_kec_eeg.parquet`
- `zuco_kec_merged.parquet`  **(compat only)** = INNER JOIN of `zuco_kec_rt` ∩ `zuco_kec_eeg` by keys:
  ```
  (lang, subject_id, task_id, doc_id, sent_id, word_id, word)
  ```

### 3.3 Models and Figures Consume **Separate Files**

- **F2 (Reading~KEC)**: read **only** `*_kec_rt.parquet` (per dataset; start with ZuCo/GECO/OneStop)
- **F3 (EEG~KEC)**: read **only** `*_kec_eeg.parquet` (per dataset; start with ZuCo/DERCo/LPP)
- **Merged** exists only for compatibility or optional bimodal analyses

### 3.4 LPP Particularities

If **LPP** is not **word-level** (e.g., sentence/passage):
- Support **sentence level**: map `doc_id, sent_id`, and **aggregate KEC** from sentence (e.g., **mean** KEC of sentence words)
- Add field `unit_level: "sentence"` in line metadata
- EEG~KEC models can use `KEC_sentence_mean` instead of `KEC_word`
- Document policy in `DATA_DICTIONARY.md` and `docs/LPP_alignment_notes.md`
