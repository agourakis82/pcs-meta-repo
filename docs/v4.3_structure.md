# Estrutura Organizada v4.3 - Quality Gates

## Visão Geral
Esta estrutura foi reorganizada seguindo os quality gates do projeto v4.3 para garantir:
- Consistência na organização de arquivos
- Facilidade de navegação e manutenção
- Compatibilidade com pipelines de QA e CI/CD
- Preparação para releases e DOI

## Convenções de Nomenclatura

### Figuras
- `F{n}_{descrição}.png` - Figuras principais do manuscrito
- `{tipo}_corrected_{descrição}.png` - Figuras corrigidas
- `{idioma}_{métrica}_{descrição}.png` - Figuras específicas por idioma

### Dados
- `{fonte}_{processamento}_{versão}.csv` - Dados processados
- `{métrica}_{análise}_{parâmetros}.csv` - Resultados de análise
- `{modelo}_{tipo}_{resultado}.pkl` - Modelos salvos

### Reports
- `{categoria}_{tipo}_{timestamp}.json` - Reports estruturados
- `{análise}_{resultado}_{parâmetros}.txt` - Reports textuais
- `qa_{componente}_{status}.json` - Reports de QA

## Scripts de Manutenção

### Verificação de Estrutura
```bash
# Verificar se todos os arquivos estão nos locais corretos
find figures/ reports/ data/processed/ -name "*.png" -o -name "*.json" -o -name "*.csv" | head -20
```

### Limpeza de Arquivos Antigos
```bash
# Mover arquivos soltos para estrutura organizada
find figures/ -maxdepth 1 -name "*.png" -exec mv {} figures/v4.3/ \;
find reports/ -maxdepth 1 -name "*.json" -exec mv {} reports/v4.3/qa/ \;
```

### Backup de Versão
```bash
# Criar backup da estrutura atual
tar -czf backup_v4.3_$(date +%Y%m%d_%H%M%S).tar.gz figures/v4.3/ reports/v4.3/ data/processed/v4.3/
```

## Manutenção Contínua

1. **Adição de Novos Arquivos**: Sempre seguir a estrutura v4.3
2. **Versionamento**: Manter compatibilidade com versões anteriores
3. **Documentação**: Atualizar este arquivo quando houver mudanças
4. **QA**: Executar verificações regulares da estrutura
